# RL-CloudSimPlus-GreenScheduling 代码框架文档

## 项目概述

这是一个基于 CloudSimPlus 的绿色调度系统，使用深度强化学习（DRL）进行云数据中心的工作负载调度优化。该项目主要使用 TimeCAP 模型进行时间序列预测，以支持能源感知的调度决策。

## 主要部件详解

### 1. 主入口模块 (`run.py`)

**功能**：程序的入口点，负责整个实验流程的控制和管理。

**主要职责**：
- 参数解析和融合
- 随机种子设置
- 设备（GPU/CPU）配置
- 实验模式选择（预训练/微调）
- 模型训练和推理流程控制

**关键流程**：
1. 解析命令行参数
2. 设置随机种子确保可重现性
3. 配置计算设备
4. 根据任务类型（预训练/微调）执行相应流程
5. 记录训练日志和结果

### 2. 参数配置模块 (`Arguments/`)

#### `run_args.py` - 运行参数配置
**功能**：定义模型运行的基本参数

**主要参数**：
- `model`: 模型名称（默认 'TimeCAP'）
- `paradigm`: 任务范式（预训练-微调/训练-验证-测试）
- `task_name`: 任务名称（预训练/微调）
- `downstream_task`: 下游任务（预测/插补）
- `seq_len`: 输入序列长度
- `pred_len`: 预测序列长度
- `mask_rate`: 掩码比例
- GPU相关配置

#### `TimeCAP_args.py` - TimeCAP模型参数
**功能**：TimeCAP模型的超参数配置

**主要参数**：
- 学习率和优化器设置
- 模型架构参数（`d_model`, `d_ff`, `e_layers`等）
- 多尺度参数（`patch_len`, `stride_time`, `window_size`等）
- 损失函数权重（`lambda1`, `lambda2`, `lambda3`）

#### `load_setting.py` - 设置加载
**功能**：加载和处理实验设置

### 3. 实验管理模块 (`exp/`)

#### `exp_TimeCAP.py` - TimeCAP实验类
**功能**：管理TimeCAP模型的完整实验流程

**核心方法**：
- `pretrain()`: 预训练阶段，使用多个数据集进行自监督学习
- `finetune()`: 微调阶段，在特定数据集上进行监督学习
- `Inference()`: 推理阶段，进行预测并计算评估指标
- `vali()`: 验证函数，计算验证损失

**关键特性**：
- 支持自回归（AR）和一次性（OS）两种预测模式
- 使用联合损失函数（AR损失 + OS损失 + 自蒸馏损失）
- 实现早停机制防止过拟合
- 支持学习率调度

### 4. 模型定义模块 (`models/`)

#### `TimeCAP.py` - TimeCAP模型架构
**功能**：定义TimeCAP多尺度时间序列预测模型

**主要组件**：
- `MultiscaleBlock`: 多尺度学习块，处理不同粒度的时间模式
- `Model`: 主模型类，整合多个多尺度学习块

**架构特点**：
- **多尺度设计**：使用不同的patch长度和步长捕获多粒度时间模式
- **双头预测**：自回归头（AR）和一次性头（OS）
- **实例归一化**：提高模型的泛化能力
- **级联结构**：多个MultiscaleBlock串联处理

### 5. 层级模块 (`layers/`)

#### `TimeCAP_EncDec.py` - 编解码器组件
**功能**：实现TimeCAP模型的核心层级结构

**主要类**：
- `DataEmbedding_MultiScale`: 多尺度数据嵌入层
- `ChannelBlock`: 通道注意力块
- `ChannelLayer`: 通道层（包含自注意力+交叉注意力+前馈网络）
- `Decoder_TimeCAP`: TimeCAP解码器
- `ChannelAttention`: 通道注意力机制

**关键特性**：
- **多尺度嵌入**：将时间序列分解为不同尺度的patches
- **通道分组**：按通道维度进行分组注意力计算
- **双重注意力**：自注意力 + 交叉注意力机制
- **位置编码**：使用旋转位置编码（RoPE）

#### `Attn_Bias.py` - 注意力偏置
**功能**：实现通道注意力的偏置机制

**主要功能**：
- 生成注意力掩码
- 控制不同通道组之间的注意力计算

#### `Attn_Projection.py` - 注意力投影
**功能**：实现查询-键的投影变换

**包含**：
- `QueryKeyProjection`: 标准投影
- `RotaryProjection`: 旋转位置编码投影

### 6. 数据提供模块 (`data_provider/`)

#### `data_factory_TimeCAP.py` - 数据工厂
**功能**：创建和管理不同类型的数据集和数据加载器

**支持的数据集类型**：
- `ETTh1`, `ETTh2`: 电力变压器温度数据集
- `pretrain_AAAI`: 预训练数据集

**主要功能**：
- 根据任务类型选择合适的数据集
- 配置数据加载器的参数（batch_size, shuffle等）
- 支持预训练和微调的不同数据处理逻辑

#### `data_loader.py` - 数据加载器
**功能**：实现具体的数据加载和预处理逻辑

**主要类**：
- `Dataset_ETT_hour`: 小时级别ETT数据集
- `Dataset_Custom`: 自定义数据集
- `Dataset_Pretrain_TimeCAP`: TimeCAP预训练数据集

### 7. 工具模块 (`utils/`)

#### `tools.py` - 基础工具函数
**功能**：提供实验过程中需要的各种工具函数

**主要函数**：
- `set_seed()`: 设置随机种子
- `make_dir()`: 创建实验目录结构
- `init_logger()`: 初始化日志记录器
- `adjust_learning_rate()`: 学习率调整
- `EarlyStopping`: 早停机制类

#### `metrics.py` - 评估指标
**功能**：计算各种预测性能指标

**支持指标**：
- MAE (平均绝对误差)
- MSE (均方误差)
- RMSE (均方根误差)
- MAPE (平均绝对百分比误差)
- MSPE (均方百分比误差)

#### `masking.py` - 掩码处理
**功能**：实现数据掩码策略

#### `losses.py` - 损失函数
**功能**：定义各种损失函数

#### `timefeatures.py` - 时间特征处理
**功能**：处理时间序列的时间特征编码

#### `args_fusion.py` - 参数融合
**功能**：合并不同来源的参数配置

#### `print_args.py` - 参数打印
**功能**：格式化打印参数配置

#### `dtw_metric.py` - DTW指标
**功能**：计算动态时间规整距离

## 核心算法流程

### 预训练阶段
1. 使用多个数据集进行自监督学习
2. 主要使用自回归预测任务
3. 学习通用的时间序列表示

### 微调阶段
1. 加载预训练权重
2. 在特定数据集上进行监督学习
3. 联合训练自回归头和一次性头
4. 使用自蒸馏损失提高性能

### 推理阶段
1. 组合自回归和一次性预测结果
2. 使用Sigmoid函数进行权重融合
3. 生成最终预测结果

## 技术特点

1. **多尺度建模**：同时捕获短时和长时依赖关系
2. **双重预测模式**：自回归保证准确性，一次性保证效率
3. **通道注意力**：利用变量间的相关性
4. **自蒸馏学习**：通过教师-学生机制提升性能
5. **预训练-微调范式**：提高模型泛化能力

## 使用方法

### 预训练
```bash
python run.py --task_name pretrain --is_training True
```

### 微调
```bash
python run.py --task_name finetune --is_training True
```

### 推理
```bash
python run.py --task_name finetune --is_training False
```

这个框架为云数据中心的绿色调度提供了强大的时间序列预测能力，能够准确预测工作负载和能源消耗模式，从而做出更优的调度决策。
