# TB13 离线筛选规格(Codex 2026-08-28 修订后冻结)

**纯离线,不建仿真考场,不训练。** 定位:下一篇的地基 / 本篇 Discussion 的证据,
**不是本篇投稿前的必做项**。

前一版(`PROPOSAL_TB13_NONFLUID_MULTIDC.md`)的指标、网格、判据**全部作废**,以本文件为准。
作废原因逐条见下。

---

## 零、立场修正

前一版称"作业不可分割性/低并发是十二次失败的共同根因"。**这个说法过强,撤回。**
唯一正例只有 TB12,而我定义的两个指标又混进了别的物理量。

现在的表述:

> **不可分割性/低并发是预测价值兑现的候选相变变量,不是已证的共同根因。**

## 一、指标重定义(替换前一版的两个)

前一版用 `Σ runtime_i / horizon` 当"并发决策数"。它同时受作业数、到达率、负载、
horizon 影响,**四个物理量混成一个**。拆成三个互不混淆的量:

| 量 | 定义 | 说明 |
|---|---|---|
| **决策并发度** | `N_eligible(t)` 的中位数与 p90 | 真正同时可决策的作业数,时间序列上量 |
| **作业粒度** | `N_eff = (Σ w_i)² / Σ w_i²` | 有效作业数;w_i 为作业能量 |
| **系统利用率** | `ρ` = 总工作量 / 总服务容量 | **全网格固定,不得随其它轴漂移** |

前一版的"单作业占 episode horizon"依赖人为设定的 episode 长度,**作废**。替换为两个物理量:

```
runtime / green_opportunity_timescale
job_energy / green_window_absorbable_energy
```

**绿电稀缺度**改为积分口径,不用瞬时峰值比:

```
κ = 可用绿电能量 / 可延期作业能量
```

## 二、空间冗余的真正旋钮是相关性,不是 DC 数

前一版把 DC 数当空间冗余的旋钮,**错**。决定"多 DC 是否吃掉时间价值"的是**各站绿电的相关性**:

- 五个**独立**风场 → 总有一个站有绿电 → 时间价值被空间替代
- 五个**同步枯竭**的站 → 加 DC 数也消灭不了等待价值
- **高相关但带少量站点差异** → 最可能同时保住空间路由与时间预测两个杠杆

因此增加**跨 DC 相关性轴**,生成方式:

```
g_d(t) = g_common(t) + ε_d(t)          common share ∈ {0, 0.5, 0.8, 1.0}
```

前一版的结论候选"多 DC 与非流体不可兼得"**过强,撤回**。最终最多能说:

> 在注册的容量缩放与绿电相关性族中,**低相关站点产生的空间冗余削弱了预测价值**。

## 三、网格(必须同时固定的量)

| 轴 | 取值 |
|---|---|
| DC 数 k | 1, 2, 3, 5 |
| 非流体性 `N_eff` | ≈ 1, 2, 5, 10 |
| common-mode 比例 | 0, 0.5, 0.8, 1.0 |
| 绿电稀缺度 κ | 0.5, 0.8, 1.0, 1.2 |
| slack / runtime | 固定在 TB12 的正区间;必要时才加第二档 |
| 系统利用率 ρ | **固定** |

**归因约束(前一版缺失,是它最大的方法学缺陷):**

- 改 DC 数时**总 VM/PE 容量不变**,只在站点间重新切分
- **总作业量与 ρ 不变**
- **总绿电预算不变**,只改站点间分布与相关性
- slack/runtime 固定或作为独立轴

## 四、盲基线必须是联合时空盲

**不得复用每 DC 独立的 TB12 blind。** 否则 clairvoyant 赢的可能是**协调能力**而不是未来信息
—— 这个混淆本项目已经遇到过一次。

最强盲必须:

- 同时决定**何时释放**与**送到哪个 DC**
- 只能读取 `t` 之前的信息
- 在注册数据上**冻结**
- 能联合利用当前绿电、队列、slack、站点状态、历史 hazard
- 与 clairvoyant 使用**完全相同**的容量、deadline、SLA、backstop

**离线筛选器本身必须是逐作业、不可分割、受容量约束的模型。**
不得用流体松弛去验证"非流体性"——那是自相矛盾。
(前一版打算复用的松弛下界正犯此错,作废。)

## 五、判据(替换前一版三条)

### 5.1 工具有效性门 —— 先过,否则一切结论无效

1. 离线模型**复现 TB12 单 DC 正例**
2. 同时**复现一个已知的流体负例**
3. **任一 anchor 不复现 ⇒ 停止**,说明筛选器无效,不能用它判任何场景

### 5.2 正区间门(全部满足才算中标)

- `k ≥ 3`
- 相对**冻结的最强联合因果盲**,clairvoyant 碳下降**中位数 ≥ 10%**
- **≥ 8/10** workload/wind 种子同向
- 配对 bootstrap **95% CI 下界 > 5%**
- 两臂**同时**满足完成率与 on-time 合同
- **≥ 3 个相邻网格格**通过,不接受孤立热点

前一版"任一格 >10%"会产生网格搜索后的偶然中标,**作废**。

### 5.3 空间替代假设 —— 看交互,不看单调性

前一版要求"随 DC 数严格单调下降",随机样本下极易被小波动打破,**作废**。改为报告效应面:

- **低相关**时价值随 DC 数明显下降
- **高 common-mode** 时价值保留
- 报告完整效应面与趋势区间,**不强求逐格单调**

### 5.4 负结果的处理

anchor 通过但**整个注册网格都不到 10%** ⇒ 这是**该场景族的干净负结果**,
如实报告,**不得写成"算法或范围可能有问题"**。

## 六、最值得找的区域(Codex 指出)

不是泛泛的"多 DC + 长作业",而是:

> **固定总容量与总负载、作业高度不可分割、绿电供给稀缺、多个站点存在共同枯竭成分,
> 同时保留少量站点差异供空间路由使用。**

物理上这个区域最有希望同时保住"去哪"和"何时"两个杠杆。
