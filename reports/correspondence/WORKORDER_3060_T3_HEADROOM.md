## B. 松弛下界 —— 纯离线,几分钟,不用仿真

对每个作业 j,能量 `E_j` 按与仿真一致的功率模型算;在其可行窗口
(`arrival_j` 到 `deadline_j − runtime_j`)内,取所有 (DC, 起始时刻) 中**边际碳强度最低**的那个:

```
carbon_relaxed = Σ_j  E_j × min_{dc, t 可行} intensity(dc, t)
```

**忽略容量与争用 ⇒ 乐观 ⇒ 真下界。** 用同一份 workload(`traces/probe_C_2xjob_dl6500.csv`)
与同三个窗口。DC 棕电强度:Nordic 0.08 / Germany 0.35 / US_East 0.55 / US_West 0.75 / APAC 0.92,
涡轮与时区 DC0=[12,36]@tz0、DC1=[95,91]@tz18、DC2=[96]@tz54,warmup **13 行**(实测,非配置)。

界可能很松,报告里必须写明,**不得当作"真实可省量"**。

## 判据(先冻,不看结果不改)

`S_ach = (盲−可达)/盲`,`S_rel = (盲−松弛下界)/盲`。当前兑现值 ≤5.2%。

| 情形 | 读法 |
|---|---|
| **S_ach > 15%** | 贪心就能拿到 ⇒ 病在**学习或杠杆**,不在考场 |
| **S_ach ≈ 5–8% 且 S_rel < 15%** | **天花板本来就低** ⇒ 该换考场 |
| **S_ach ≈ 5–8% 但 S_rel > 30%** | 界太松、贪心太弱 ⇒ **无结论**,需更强的全知策略 |
| 盲态 ≤ 可达 | 全知臂**无效**,报 undefined,**不反转解释** |

第三行是"测不出来"这个诚实结局的位置。没有它,一个弱贪心会被误读成"天花板低"。
