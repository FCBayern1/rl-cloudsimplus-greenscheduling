## 二、批准并建议优先:TB12 窗长特征探针

比 T3 重做更值得投,因为 **TB12 的奖品是认证过的**(−17.51%,六门),缺的只是一个特征。

### 依据

TB12 预注册自己写的、盲态答不上来的问题:

> **"当前绿窗装不装得下我、值不值得等下一个"** —— 真实风窗中位 30min、CV≈2.4,
> **窗长不可由窗龄可靠预测**

表示审计 Run 2 学不出来的:42 个分歧作业上 `|p_fc−p_nofc|` 中位 **0.0072**。

而现役四个特征 `short_mean / short_trend / long_mean / peak_timing`
**没有一个表达"窗长"**。`peak_timing` 最接近,但它是**时刻**不是**时长**。

**决策问的是"这个窗装不装得下我",喂进去的是"未来平均有多绿"。特征回答的不是那个问题。**
这也解释你们筛选里那条限定:预测未来绿电很强(ΔR²=0.72),预测该不该等这个作业不行。

### 要测的特征
```
window_remaining        当前绿窗剩余时长(绿电 > 阈值的连续时长)
next_window_onset       下一个窗多久到
next_window_size        下一个窗的时长 × 强度
fits_current            window_remaining / job_runtime      ← 直接对"装不装得下"
fits_next               next_window_size / job_runtime      ← 直接对"值不值得等"
```
阈值定义请你们定并写死(建议按该 DC 绿电的某个分位数),**先冻再测**。

### 怎么测
**用 Run 2 那套已修好的仪器**(每作业等权 + 作业内类别平衡 BCE,G4 健康门已通过)。
把新特征加进 fc 侧,重跑同一批 42 个分歧作业,看 `|p_fc−p_nofc|` 和 OOF 准确率是否起来。

**几小时,不训练。** 判据建议(先冻):
- `|p_fc−p_nofc|` 中位 **≥ 0.05**(现役 0.0072)且 OOF 准确率相对 nofc 提升 **≥ 0.03**
  ⇒ 方向有救,值得谈 RL
- 达不到 ⇒ TB12 这条线**到头**,如实报告

结果为正属**新工作 + 新预注册**,不回改任何既有负结果,不改变 G1 的 STOP,
T116+117 继续封存。
