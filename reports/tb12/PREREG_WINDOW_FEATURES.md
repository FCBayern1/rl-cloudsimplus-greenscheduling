## 问的问题

TB12 预注册说盲态答不上的是「**当前绿窗装不装得下我、值不值得等下一个**」;
表示审计 Run 2 显示学不出来(42 个分歧作业上 |p_fc−p_nofc| 中位 **0.0072**)。
而现役四特征 `short_mean / short_trend / long_mean / peak_timing`
**没有一个表达"窗长"** —— `peak_timing` 最接近,但它是**时刻**不是**时长**。

> 决策问的是"这个窗装不装得下我",喂进去的是"未来平均有多绿"。

## 冻结:绿窗阈值定义(先冻再测)

绿窗 = 该 DC 绿电功率 **> θ_dc** 的**连续**行段,其中

    θ_dc = 该 DC 在**训练分布 T100+101/2021 全年**绿电序列的 **60 分位数**

- 按 DC 各自定,不跨 DC 共用;
- 分位数从**全年**算,与 episode 无关 ⇒ 不随窗口漂移,不可事后调;
- 选 60 分位的理由:低于中位会把长时间的低风也算成"窗",高于 75 分位则窗
  过于稀疏;**60 分位在冻结前一次选定,不因结果回调**。

## 冻结:五个候选特征(逐作业,在其首次 eligible 决策点上)

```
window_remaining    当前绿窗剩余行数(不在窗内则 0)
next_window_onset   到下一个窗起点的行数(窗内则 0)
next_window_size    下一个窗的 时长 × 平均强度
fits_current        window_remaining / job_runtime      <- 直接对"装不装得下"
fits_next           next_window_size / job_runtime      <- 直接对"值不值得等"
```
全部按**真实未来风**(godeye 口径)计算 —— 这是"信息在不在"的上界检验;
若连真实未来都撑不起判别力,预报器版本更不可能。
