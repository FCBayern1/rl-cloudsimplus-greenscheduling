## 逐轮判决(全部保留,无改判)

### 1. 冻结策略链 —— 认证通过并封存
- **T114+115 六门全过**(Round 3 终判):见上表。Codex 独立复核后批准收兵,
  不开第四轮。
- **复活测试**:displaced 污染下"信任坏预报"(8.807)比"不调度"(8.099)更差;
  修复臂与 greenfollow **逐位相同 120/120**。
- **检测延迟代价曲线**(displaced,K=2,20 偏移):确认窗
  30min/1h/5h/15h → 修复超盲 **0.00% / +2.64% / +36.18% / +72.49%**,
  危害拦截率 100% / 97% / 58% / 16%。现役 30 分钟窗恰在零损伤区。

### 2. RL v1 —— 负结果(奖励漏洞)
- capture **−943%**;RL_fc 比 RL_nofc **差 +26.05%**,逐格仅 13/60 胜。
- 根因(P0 代数审计,零训练):恒等式 1、3 逐位 PASS(簿记自洽、两本碳账一致),
  恒等式 2 揭底 **3.0 封顶抹掉 97% 的碳** —— `fixed_max=2e-05` 按 gwo1 尺度
  沿用,实际错配 **497.8 倍**。

### 3. v2 修复 —— 三处真 bug
- `fixed_max` 重标 **6.637e-3**(推导规则 C_max_cal/1.5,封顶零触发);
- `sla_mode: ontime_mi` 对齐判决合同;cap 监控导出并接硬止损;
- **backstop per-PE runtime 修复**:`length/(pes×mips)` 低估 2 倍 →
  2-PE 作业强制释放晚开火 ~1.8h,**此即坍缩臂 ontime=0 的直接原因**。
- v2 50k:**G3 FAIL**(fc 全 defer,6/6 偏移 forced=5、defer_frac=1.0)。

### 4. v3 修复(Codex 的 defer 计费修复 `13348ae`)—— 漏洞闭合但仍未学会
- 首次显式 defer 精确收一次 −0.5,重复 defer 不重复收,总等待成本与重现
  次数无关 —— 事件级哨兵全格 PASS。
- v3 50k:G1 PASS(**空真**)、G2 PASS(ontime 1.0)、G3 诊断 PASS、
  **G4 FAIL**(fc 与 nofc 逐偏移碳差**全零**)、**方向门 FAIL**。
- 失败模式**与 v2 相反**:v2 全 defer 套利,v3 全 route 停滞(= ck0 行为)。
- **共享标量 credit 的定量证据**:11 个分歧样本上
  corr(Δp, **初始概率**) = **+0.9714**,corr(Δp, **目标方向**) = +0.4489;
  初始概率单变量解释 **R² = 0.944**,逐作业残差 std 仅 **0.00035**。
  (按 Codex 提醒克制措辞:强一致性证据,非"数学上不可表达"的证明。)

### 5. 小样本 gate-only BC 探针 —— FAIL
- C1 FAIL(池化 +0.127 过阈但仅 **3/5** 偏移正向);
  C2 FAIL(**nofc +0.165 > fc +0.127**);C3 PASS。
- **留一交叉验证两臂皆负**(fc −0.124 / nofc −0.046)⇒ in-sample 移动是记忆。
- 定稿措辞:**小样本 BC 探针 FAIL;不能证明映射可泛化。**
- 有效性已排除"两臂无差别":corpus 对拍 **7 个预报键确实不同、22 个非预报键
  逐位相同**。

### 6. 表示能力审计 Run 1 —— 执行有效,G4 失败 ⇒ 主推断无效/不确定
- 四门皆 FAIL,但 **G4(仪器健康门)失败使 G1–G3 失去意义**:
  逐折 train acc **逐位等于多数类基线**(两臂 × 5 折,10 组全中),
  OOF hold 率 0.961/0.964 ⇒ 学习器坍缩为多数类预测器。
- **Codex 在预注册里加的 G4 正是为拦此情形而设,并成功拦下** ——
  否则会基于坏掉的仪器关闭一条研究线。
- 根因假设:标签类不平衡且**结构性**(每作业贡献 1 个 route 标签和 N 个
  hold 标签,N = 等待步数)。

### 7. 表示能力审计 Run 2(仪器修复)—— **终局否定**
- 修复方案(Codex 冻结,无自由参数):**每作业等权 + 作业内类别平衡 BCE**
  (hold 权重 1/(2H)、route 权重 1/(2R),单类别作业总权重 1,归一化均值 1)。
  **明确不用 pos_weight** —— hold=1 恰是多数类,正权重会加剧坍缩。
- **G4 PASS ⇒ 仪器健康,Run 1 的不平衡假设确认**:
  逐折加权 acc **0.68–0.76**(平衡基线 0.50);OOF hold 率 **0.892/0.887**;
  **第一折「只停不调」哨兵两臂均通过**(0.919/0.914)。
- **G1–G3 FAIL 且为有效推断**:
  G1 池化 E[s] **−0.0041**(阈 +0.05,方向为负);
  G2 **1/5** 块正向(−0.0022/−0.0098/−0.0019/−0.0094/+0.0053);
  G3 CI **[−0.0084, +0.0003]** 含 0。
- 支撑读数:分歧作业 **n=42**;\|p_fc−p_nofc\| 中位 **0.0072**(最大 0.0521);
  signed score 中位 −0.0038、仅 **13/42** 为正;
  两臂 OOF 总体准确率 **0.7988 vs 0.7968** 几乎相同。

**forecast 观测通道本身**。因此下一步应是**重新设计预报特征**

达到与 fc 几乎相同的准确率(0.7968 vs 0.7988),说明现有特征基本是当前绿电
的重述。
