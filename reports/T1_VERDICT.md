# T1 判决 —— "信息稀薄"假设被推翻,两条判据均不支持

2026-08-27。口径冻结于 `reports/T1_T2_SPEC_FROZEN.md`(Codex 升级版),写在跑之前。
数据:三个注册窗口各 6105 步的全局观测(`g1/t1/obs_k*.csv`),三个绿电 DC。
全部回归为 **blocked OOF,5 折连续块**,无随机行切分。

## 第一层 冗余度:不冗余

用盲态可见变量预测 forecast 特征(blocked OOF R²):

| 特征 | 外生子集 | 全盲集 |
|---|---|---|
| `dc_future_short_mean` | 0.2697 | 0.2274 |
| `dc_future_short_trend` | 0.0067 | 0.0013 |
| `dc_future_long_mean` | **−0.5863** | **−0.7413** |
| `dc_future_long_peak_timing` | −0.0146 | −0.0671 |

判据是 **R² > 0.7 才算高冗余**。全部远低于,`long_mean` 甚至为负
(盲态变量预测它比直接用均值还差)。

**预报特征不是当前绿电的重述。**

## 第二层 条件价值:信息真实存在,集中在长视界

`ΔR² = R²(blind+forecast) − R²(blind)`,目标为未来 H 行的实现绿电:

| 视界 H | R²(blind) | R²(+预报) | ΔR² | 各 DC |
|---|---|---|---|---|
| 1 | 0.9317 | 0.9343 | 0.0025 | +0.002 / +0.001 / +0.001 |
| 3 | 0.8775 | 0.8916 | 0.0141 | +0.010 / +0.013 / +0.003 |
| 6 | 0.8128 | 0.8450 | 0.0322 | +0.028 / +0.045 / +0.026 |
| **12** | 0.6891 | 0.7798 | **0.0908** | +0.085 / +0.115 / +0.078 |
| **24** | 0.4699 | 0.6847 | **0.2149** | +0.215 / +0.250 / +0.170 |

判据是 **ΔR² < 0.05 才算信息稀薄**。H=12 与 H=24 都远超,且三个 DC 方向一致。

## 判决

```
第一层  R² > 0.7 ?     否(最高 0.27)
第二层  ΔR² < 0.05 ?   否(H=12 为 0.091,H=24 为 0.215)
```

**两条同时成立才支持"被大量使用但几乎不携带独立信息"。两条都不成立,假设被推翻。**

与 TB12 收官结论的"汇合"读法在 C-regime 上**不成立**,该说法撤回。

## 顺带排除的第三个解释

档案里的"作业太短 ⇒ 承诺窗口≈0"在这个考场也不适用。
workload `probe_C_2xjob_dl6500.csv`,VM PE 40000 MIPS:

```
作业运行时长   中位 37.5 步   p10 15.6   p90 59.7
≥12 步占比 93.5%      ≥24 步占比 79.1%
```

**承诺窗口够得着信息所在的视界。** 且 γ=0.999 下 37 步折扣为 0.964,信用也传得到。

## 剩下的矛盾

```
预报携带的信息    H=12 时 ΔR² = 0.091,H=24 时 0.215
承诺窗口          中位 37 步,够长
折扣              γ=0.999,够远
兑现的价值        ≤ 5.2%(上界,1/4 种子为负)
```

信息在、杠杆够得着、信用传得到,**价值却没兑现**。这是一个真实的谜,不是测量误差。

T2(No-Forecast,运行中,明晚出)给出兑现价值的直接读数,会把这个矛盾收紧到一个数上。
